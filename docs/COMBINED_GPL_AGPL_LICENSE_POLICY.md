# Combined GPL and AGPL license policy

FieldVox Lab is licensed under both:

- GNU General Public License, version 3 or later.
- GNU Affero General Public License, version 3 or later.

This is an AND-style combined copyleft policy, not an OR-choice.

## Why

The project should remain free and open source if someone forks it, modifies it, redistributes it, or turns it into a hosted/network service.

The GPL protects ordinary redistribution of the app and runtime. The AGPL additionally protects network-interactive uses by requiring modified network versions to offer corresponding source code to users who interact with them over a network.

## Practical rule

If you distribute a modified FieldVox Lab app or binary, provide the corresponding source under the same combined copyleft terms.

If you run a modified FieldVox Lab service, web app, API, server component, cloud backend, or other network-accessible version, provide users interacting with that service a clear way to receive the corresponding source code under the same combined copyleft terms.

## Compatibility

GNU GPL version 3 and GNU AGPL version 3 include section 13 compatibility language for combining GPLv3-covered and AGPLv3-covered works. FieldVox Lab uses that compatibility path intentionally.

## Non-goals

This license policy does not add proprietary restrictions, non-commercial restrictions, anti-fork restrictions, or closed-source exceptions. Commercial use is allowed, but the same copyleft source-sharing duties apply.
