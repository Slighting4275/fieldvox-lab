# FieldVox Lab

FieldVox Lab is an experimental, audit-oriented Android ITC and sensor workstation. The Android app is implemented as an `android.app.NativeActivity`: project runtime code is C and Zig, station data is a CRC-checked binary blob, and there are no project Java, Kotlin, or C++ runtime sources.

FieldVox does not claim that sensor changes or audio fragments prove paranormal activity. It records and displays physical signals so sessions can be reviewed without hiding where a sound or trigger came from.

## Current native feature set

- 64-slot station metadata plan generated by Zig and embedded as a packed binary blob.
- Offline single and dual carrier sweeps. Dual mode uses independent forward and reverse slot-derived formant grains at different cadences.
- Optional microphone monitor through native AAudio.
- Native voice-band filter (300 Hz–3.4 kHz), echo, Schroeder reverb, granular pitch shift, noise layer, and reverse-block processing.
- True 256-point FFT analysis feeding a 64-bin live spectrum display.
- Five-second native PCM ring buffer; **MARK HIT** exports the preceding three seconds as 48 kHz, 16-bit mono WAV.
- Session WAV recording in app-private storage.
- Live magnetometer magnitude/delta, gravity-rejected vibration, barometric delta, and compass telemetry using the NDK sensor API.
- One-tap EMF/barometer baseline calibration.
- Sensor-driven four-tier REM-pod tone synthesis in Zig.
- Equal-power stereo panning driven by compass azimuth.
- Estes mode with AMOLED blackout, blind hit logging, and a visible top-right exit target.
- Real Camera2 NDK viewfinder using an `AImageReader`, with phosphor-green and darkroom-red luma rendering plus reticle and sensor HUD.
- Runtime microphone and camera permission requests made from native code through the Android VM; no app-side Java bridge.

The station blob contains station names and source URLs for provenance. The current zero-Java NativeActivity does **not** decode those internet streams: SWEEP and SB11 DUAL are explicitly labeled offline and synthesize deterministic formant grains. This avoids presenting generated audio as a live broadcast.

## Controls

| Control | Behavior |
| --- | --- |
| `CAL ZERO` | Sets the current magnetic and pressure readings as the local baseline. |
| `SWEEP` | Enables the offline single carrier sweep. |
| `SB11 DUAL` | Enables two independent, differently timed offline sweepers. |
| `VOCAL` | Restricts audio to the approximate telephone/voice band. |
| `ECHO` | Enables a 150 ms feedback delay. |
| `REVERB` | Enables native Schroeder reverb. |
| `PITCH` | Enables the native granular pitch shift. |
| `NOISE` | Adds a low white-noise floor. |
| `REMPOD` | Enables sensor-tiered audible alert tones. |
| `3D PAN` | Maps compass azimuth to equal-power stereo gains. |
| `ESTES` | Enters a blind-listener screen; tap to log hits, tap the top-right exit target to leave. |
| `CAM HUD` | Starts the native Camera2 viewfinder; tap the preview to switch green/red rendering. |
| `MARK HIT` | Saves the prior three seconds from the native PCM ring. |
| `RECORD` | Starts/stops a 48 kHz mono session WAV. |
| `REVERSE` | Reverses each current audio block. |
| `MIC MON` | Adds the microphone input to the native processing chain. Headphones are recommended. |

Artifacts are stored under the app-private `files/fieldvox-hits` directory. They can be inspected on a debug build with:

```bash
adb shell run-as org.fieldvox.lab ls -lh files/fieldvox-hits
```

## Architecture

```text
station_blob_gen.zig
        │
        ├── fieldvox_station_plan.bin
        └── fv_station_blob_data.h
                    │
                    ▼
android.app.NativeActivity
        │
        ├── fieldvox_native_activity.c  lifecycle, framebuffer UI, sensors, AAudio
        ├── fv_native_camera.c          Camera2 NDK + AImageReader
        ├── fv_stage1r_native_audio.c   FFT, pre-roll, filters, DSP
        ├── fieldvox_zig_dsp.zig        pressure tracker, spatial gains, REM tones, CRC
        ├── fv_stage1u_native_blob_decoder.c
        └── fv_core.c / fv_source_audit.c
```

The Zig DSP source is cross-compiled to a PIC object for each Android ABI and linked into `libfieldvox_native.so`. The APK currently targets `arm64-v8a` and `x86_64`.

## Build

Requirements:

- Arch Linux or another recent Linux distribution
- Android SDK and NDK
- Zig 0.16 or compatible
- JDK 17+
- C11 compiler for host tests

Build the Android debug APK:

```bash
cd android
ANDROID_HOME=/home/baconfat/Android/Sdk ./gradlew :app:assembleDebug
```

The output is `android/app/build/outputs/apk/debug/app-debug.apk`.

Install and launch:

```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n org.fieldvox.lab/android.app.NativeActivity
```

## Generate and verify blobs

Regenerate the packed station plan and C header:

```bash
make -C source blobgen
```

The generator writes:

- `android/app/src/main/assets/fieldvox_station_plan.bin`
- `android/app/src/main/cpp/fv_station_blob_data.h`

The blob format has a 16-byte header followed by 64 fixed-size station records. Both native C tests and the linked Zig runtime validate its magic, record count, and CRC-32.

## Tests

Run host native unit and smoke tests:

```bash
make -C source clean
make -C source test
```

Build every Android native ABI:

```bash
cd android
ANDROID_HOME=/home/baconfat/Android/Sdk ./gradlew :app:assembleDebug --rerun-tasks
```

Confirm that there are no tracked Java or C++ runtime sources:

```bash
git ls-files '*.java' '*.cpp'
```

The command should print nothing after the migration is committed.

## Permissions and privacy

- `RECORD_AUDIO` is used only when the native microphone stream is available.
- `CAMERA` is used only by the Camera2 NDK HUD.
- `INTERNET` remains declared for station/source metadata evolution, but the current offline sweep does not fetch or decode internet audio.
- Session recordings remain in app-private storage unless the user deliberately extracts them with Android debugging tools.
- No TTS, generated words, hidden phrase selection, or semantic response engine is used.
